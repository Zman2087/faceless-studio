# Your daily routine (about 2 minutes)

1. Open the studio page (pin it in the Claude sidebar). The **Up next** list puts anything ready first.
2. If a post says **Needs your OK** (only when `approval_mode` is "owner"): read the script, then **Approve script** or **Send back with note**.
3. Open a **Ready to post** video:
   - **Video** → save it. **No subtitles** is there too if you prefer the app's own captions.
   - **Thumbnail** → save it (Instagram and YouTube let you pick a cover).
   - Copy the caption + hashtags for each app.
4. Post the same video to TikTok, Instagram Reels and YouTube Shorts. **Turn on the AI-generated label** in each app.
5. Tap **Mark as posted**.
6. If the post was a viewer request, reply to their comment with the video (the reply text is in the post).

**Weekly:** open each posted video and type in its views (TikTok, Reels, Shorts) → **Save views**. The
planner reads them on Sunday to decide what to make more of.

**Comments asking for a video?** Add them under **Viewer requests**; the planner makes those first.
